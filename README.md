# Open Kannada Homebrew tap

Homebrew formulae for [Open Kannada](https://github.com/openkannada) tools, for macOS and Linux.

```sh
brew install openkannada/tap/kannadi
```

| Formula | What it installs |
|---|---|
| `kannadi` | The `kannadi` command from [openkannada/kannadi](https://github.com/openkannada/kannadi): converts Kannada documents typed in Nudi, Baraha, Nudi B-Akshara, Kan-Eng, Akruti and Shree-Lipi fonts to Unicode, and Unicode to Nudi. With its man pages and bash, zsh and fish completions. |

Each formula installs the prebuilt archive from the tool's GitHub Release and checks it against the release's SHA-256 checksum. The formulae are written by each tool's release workflow, so changes belong in the tool's repository; issues are welcome there.

Part of [Open Kannada](https://github.com/openkannada), free and open-source tools that make Kannada work properly on computers.
